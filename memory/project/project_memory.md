## Hard Constraints
- All equipment and decoration data must be in simplified Chinese
- Armor data must include: name, rarity, maximum defense, attribute resistances, slots, skills and levels
- 护石数据需区分可制作护石和个人拥有护石
- 护石孔位中，数值>4的为武器孔，1-4为防具孔，三个孔位独立判断类型
- 技能填充需严格检查技能上限(SKILL_CAPS)，防止溢出浪费孔位
- 武器孔和防具珠需严格区分，武器珠只能插武器孔，防具珠只能插防具孔
- 技能数值计算以片手剑为准，连击技能仅计算2段数值
- 配装搜索需纳入系列技能和组合技能的防具选择，不能通过珠子/护石获得
- 系列技能需同系防具2件出效果Ⅰ，4件出效果Ⅱ；组合技能需同组防具3件发动
- 武器洗练最多可出1个系列技能+1个组合技能
- 黑蚀龙之力1需与无我之境3搭配使用，提供额外+10%会心
- 泡狐龙之力需与因祸得福技能搭配使用；煌雷龙之力需与力量解放技能搭配使用
- 霸主之魂技能优先出，除非牺牲它可获得更大提升
- 技能满不满级收益差距明显时，可考虑牺牲部分舒适化技能（如减少空插槽）以达成满级
- 减轻胆怯和缓冲是两个独立技能，减轻胆怯最高三级（对应耐冲珠），缓冲最高一级（对应缓冲珠）
- 极限突破规则：R5防具突破后三个孔位等级都+1，R6防具突破后前两个孔位等级+1，均遵循三级孔位上限
- 武器孔位与防具孔位需明确区分，3-3-3为武器孔位格式
- 预留孔位需求需转化为“孔位技能”匹配，如“3个Lv1插槽技能”即预留3个任意等级空孔位
- 火龙之力2件=灼热化Ⅰ，提供等效+80伤害
- 武器面板计算需包含激化和词条：属性激化-5会心+40属性；最优词条为攻四EX×2 + 属三EX×2 + 锋二EX（+24攻击+160属性）
- 霸主之魂提供攻击力×1.05独立乘区
- 追加技能模式中，护石作为第6部位参与搜索（head→body→arms→waist→legs→charm）
- 配装算法需平等对待所有技能，不使用分数加权
- 系列技能最高4级，组合技能最高3级
- 属性吸收技能1-3级提升属性值40/50/60，需按50%覆盖率计算
- 巧击、属性吸收、锁刃刺击等片手剑不常用或难计算的技能不纳入计算
- 护石自带的武器技能与防具技能本质相同，应统一处理，不区分来源
- 配装算法需同时追踪防具和武器技能的赤字，避免无效路径搜索
- 早期可行性检查需传入包含武器技能的完整fixed_skills，而非仅armor_fixed
- 护石中的武器技能应被纳入技能累加和赤字计算，不应被视为仅能通过插珠获得
- 追加技能搜索需移除挑战者5和弱点特效5的技能模板要求
- 当指定武器元素时，对应元素的属强需参与追加技能列表
- 系列技能黑蚀2、火龙2、凶爪2、冻峰2、锁刃2需常驻参与追加
- 各级孔位需参与追加技能搜索
- 固定技能中未满级的需参与追加技能搜索
- 冻峰龙和锁刃龙系列技能仅查询等级，不参与伤害计算
- 孔位最大化采用二分搜索（最多4次DFS调用）替代线性降级搜索，提升速度
- 孔位作为“LvN插槽”技能参与搜索，预留时从防具/武器孔中扣减对应等级孔位
- 孔位技能在合并需求时跳过，不被当作需要珠子的普通技能
- DFS全局预检查跳过孔位技能的珠子存在性检查
- 系列技能和组合技能属于NO_DECO_SK集合，不检查珠子可行性，不产生珠子赤字
- 系列/组合技能在_fill_slots的armor_fixed中排除，不尝试用珠子填充
- DFS件数剪枝需包含combo_skills中的系列/组合技能（如霸主之魂3件、火龙之力2件）
- 追加技能计算需同时输出伤害增幅和加权会心
- 追加技能查询应复用现有DFS，通过封装can_solve(fixed_skills + {target: lv}, max_results=1)函数实现
- DFS需采用生成器切片实现200ms软超时，超时后返回已收集结果而非空
- DFS需加入状态缓存（Memoization）避免重复搜索已访问的装备组合状态
- DFS需实现乐观估计剪枝：若剩余部位最高评分装备总和无法超越当前最优解则整支剪除
- 追加模式需强化支配检查，将装备支配判断前置到选装备前
- 追加模式候选装备应按“解决赤字能力”排序，使优解更早被发现以触发乐观剪枝
- 追加技能模式中beam宽度(bw)需适当调大（如400）避免正确组合被截断
- 武器技能（如龙属性攻击强化、会心击【属性】）剪枝逻辑需优化，避免因武器孔位少而误杀正确方案
- 巨戟龙铠甲β等关键装备需保留全部不进行去重
- 攻势技能仅在怪物处于异常状态(毒/麻/眠/爆破)时生效，需按50%覆盖率计算
- 巨戟龙系列技能（巨戟龙的默示录）需怪物进入怒状态才能触发，按70%覆盖率计算
- 追加技能查询中，孔位技能的升级搜索需跳过（其最大化已由二分搜索处理）以避免超时
