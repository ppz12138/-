## 2026-07-30 武器系统理解与伤害模型最终修正

### 武器系统理解（已确认）
1. **武器洗练**: 1个系列技能(Lv1) + 1个组合技能(Lv1)
   - 组合技能是纯随机的，如果没洗出理想组合，武器中只有系列技能可用
2. **防具技能**: 每件防具附带1个系列技能 + 1个组合技能（巨戟防具特殊，每件2个系列技能）
3. **系列技能**: 只能通过装备凑件数，无珠子/护石
   - Lv2需2件，Lv3需3件(GROUP_SK)或3件(非GROUP)，Lv4需4件
   - 武器提供1件（计入总件数）
4. **组合技能**: 同系列技能，来源是武器和防具，不包括珠子和护石
5. **匹配算法**: 系列/组合技能匹配算法跟其他技能一样
   - 区别仅在于：武器自带技能直接计入总技能值，不需要从装备重复凑

### 伤害模型修正
1. **PERM_ATK = 11**（护符+6 + 猫饭+5 = 技能加区，不计入面板）
   - 旧错误值30（护符6+9+猫饭短期催眠术15）是臆想的，用户只说了护符+6和猫饭+5
2. **攻击守势状态化**: 从 `og = 1+(mul-1)*cov` 改为独立状态参与概率组合
3. **黑蚀覆盖率**: 无无我50%，有无我3才60%（原60%错）
